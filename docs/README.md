# Sora Development Documentation

This directory contains the durable project knowledge required to develop Sora without relying on individual chat history.

## Governing documents

- `SORA_PROJECT_CONSTITUTION.md` — permanent project rules and authority.
- `SORA_TEAM_OPERATING_SYSTEM.md` — team roles, workflow, handoffs, and gates.

## Architecture

- `ARCHITECTURE/SORA_ARCHITECTURE_BASELINE.md` — current technical baseline and boundaries.

## Workflow

- `WORKFLOW/SORA_WORKFLOW_STATE.md` — current active task, owner, state, and exact next action.

## Future document areas

```text
ARCHITECTURE/     architecture decisions and contracts
EDUCATION/        curriculum evidence and learning specifications
GAME_DESIGN/      gameplay specifications
TECHNICAL/        implementation-ready technical specifications
DECISIONS/        durable architecture/product decisions
WORKFLOW/         active execution and handoffs
```

## Rule

If a decision, requirement, constraint, or handoff matters to future work, it belongs in the appropriate repository document—not only in a chat conversation.
